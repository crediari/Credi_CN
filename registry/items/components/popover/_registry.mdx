---
name: popover
type: registry:ui
title: Popover
description: Floating popover anchored to a trigger.
dependencies:
  - "@base-ui/react"
---

Use a popover for extra content that should stay near the trigger.

```tsx
import { Popover, PopoverContent, PopoverTrigger } from "@/components/ui/popover";

<Popover>
  <PopoverTrigger>Open</PopoverTrigger>
  <PopoverContent>Conteúdo extra.</PopoverContent>
</Popover>
```
