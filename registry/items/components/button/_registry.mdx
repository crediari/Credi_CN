---
name: button
type: registry:ui
title: Button
description: Button with variants, sizes, and Base UI render support.
dependencies:
  - "@base-ui/react"
  - class-variance-authority
---

Use the button for actions, links via `render={<a href="..." />}`, and icon-only controls.

```tsx
import { Button } from "@/components/ui/button";

<Button>Salvar</Button>
<Button variant="outline" size="sm">Cancelar</Button>
```
